# 🤖 JARVIS - Conversational PDF NLP Chatbot

JARVIS is a Python-based conversational chatbot with PDF document intelligence.

## Features

- PDF upload
- PDF text extraction
- NLP-based document search
- TF-IDF vectorization
- Cosine similarity
- PDF question answering
- PDF summarization
- Conversation context
- Source page references
- Streamlit web interface

## Technologies

- Python
- Streamlit
- PyPDF
- scikit-learn
- TF-IDF
- Cosine Similarity
