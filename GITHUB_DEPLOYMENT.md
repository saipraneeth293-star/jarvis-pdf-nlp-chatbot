# JARVIS Deployment Guide

## 1. Project Repository

GitHub repository:

https://github.com/saipraneeth293-star/jarvis-pdf-nlp-chatbot

## 2. Local Test

From the JARVIS project directory:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m streamlit run app.py
```

Open the local URL shown by Streamlit, normally:

```text
http://localhost:8501
```

## 3. GitHub

Add and commit the final project:

```powershell
git add .
git commit -m "Finalize JARVIS chatbot"
git branch -M main
git push origin main
```

The repository should contain:

```text
app.py
requirements.txt
README.md
PROJECT_REPORT.md
GITHUB_DEPLOYMENT.md
.gitignore
```

Do not commit:

```text
venv/
.venv/
__pycache__/
*.pyc
*.pkl
*.pdf
.env
.streamlit/secrets.toml
```

## 4. Streamlit Community Cloud

Open:

https://share.streamlit.io/

Sign in using the GitHub account that owns the repository.

Create a new app and set:

```text
Repository: saipraneeth293-star/jarvis-pdf-nlp-chatbot
Branch: main
Main file path: app.py
```

Click **Deploy**.

The `requirements.txt` file in the repository root contains the dependencies used by the application.

## 5. Public Access

After the application is deployed, use its Streamlit URL:

```text
https://YOUR-STREAMLIT-APP.streamlit.app
```

If the application is configured for public sharing, anyone with this URL can open the JARVIS interface.

## 6. Add the Live URL to GitHub

Open the GitHub repository and update:

- `README.md`
- `PROJECT_REPORT.md`

Replace:

```text
https://YOUR-STREAMLIT-APP.streamlit.app
```

with the real URL generated by Streamlit Community Cloud.

You can also put the same URL in the GitHub repository's **About / Website** field.

## 7. After Code Changes

When you change `app.py` or another project file:

```powershell
git add .
git commit -m "Update JARVIS"
git push origin main
```

The connected Streamlit deployment can then rebuild from the updated GitHub repository.

## 8. Deployment Notes

- Keep `requirements.txt` in the repository root.
- Do not upload your local virtual environment.
- Do not upload private PDF documents to a public repository.
- Do not store passwords or API keys in the repository.
- The current version intentionally uses a lightweight NLP implementation to keep the Streamlit deployment simple and reliable.
